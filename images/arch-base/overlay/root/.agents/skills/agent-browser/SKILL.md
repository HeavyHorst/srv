# agent-browser

Use the preinstalled `agent-browser` CLI for browser automation.

Before the first browser command in a task, load the workflow matching the installed CLI version:

```bash
agent-browser skills get core
```

Use `agent-browser skills get core --full` when the full command reference or templates are needed.
